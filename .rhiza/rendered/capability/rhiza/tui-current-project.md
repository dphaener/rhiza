# tui-current-project

capability · `01M6RN86H70DC8GP65XJEDD2FN` · parent [rhiza](../rhiza.md)

## acceptance

TUI app tests opened in a project folder, in a sibling worktree and at the root check the header names the project, the project and no project.

## statement

Each Rhiza TUI app knows its current project, the project whose folder or <project>.<slug> worktree holds the directory it was opened in, and names it in its header.
