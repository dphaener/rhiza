# spawn-ends-on-done

capability · `01M7M2DV5ES8B1RNXF8R2JYEP0` · parent [workflow-runs](../workflow-runs.md)

## acceptance

go test -trimpath ./internal/api -run 'TestRunSpawn|TestStepRunnerChild' passes and covers: a child whose record has a done mark and no exit, with a Tab.Block, makes spawn return outcome pass with detail said done, journal the spawn ended with pass, and run rex block close on that block (ctx.Exec captured); stepRunner.Child reports such a child ended with pass; a child whose record has a done mark and a later non-zero exit (as when its pane was closed and its agent killed, and also when markLostIfEnded marks it lost) makes both spawn and stepRunner.Child report pass with detail said done, the done mark winning over the exit; (failure case) a live child with neither a done mark nor an exit keeps spawn waiting (it sleeps) until a later poll finds it exited 3, then spawn returns fail with exit 3 and closes no pane; (failure case) a rex close that errors still returns pass and the journaled end; go test -trimpath ./cmd/rhiza -run 'TestScripts/(run-spawn|describe-golden)' passes, describe-golden after -update if the RunSpawnResponse outcome description changes, with docs/reference/cli.md regenerated by rhiza docs to match.

## files

internal/api/run_spawn.go, internal/api/run_spawn_test.go, internal/api/run_spawn_child_test.go, cmd/rhiza/testdata/script/describe-golden.txtar, docs/reference/cli.md

## must_not

Wait for the child's process to exit once it said done; fail the spawn or drop its journaled end when the pane close fails; change the engine's own step polling (internal/run/engine.go) or session.done; start or close anything from the daemon process; touch the network or a real rex in tests

## statement

rhiza run spawn ends its wait as soon as the child session said done (pass, detail said done), journals the child's end, then closes the child's Rex pane so its agent exits, with or without a daemon; a child that exits without saying done ends as before, from its exit.
