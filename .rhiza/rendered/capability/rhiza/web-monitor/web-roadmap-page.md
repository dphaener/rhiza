A web package test renders /roadmap over a fixture with two milestones and a backlog and asserts the same groups and order as the roadmap operation, each change set's state and link.

The Roadmap page at /roadmap shows the groups in the order rhiza roadmap gives them (each milestone, then the backlog, then each umbrella, labelled as such), each change set with its intent and state, linking to its change set page; it re-renders live when a change set moves.
