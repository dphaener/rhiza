# quick-launch-layer

capability · `01M62JP7BKA4N9W2HCFTP0CMQ4` · parent [rhiza](../rhiza.md)

## acceptance

With a fake Rex client, the installed script binds the launch key to open the layer, the layer lists each registered app by name, and selecting one opens that app's modal.

## statement

ctrl+a a (the launch key, a setting in rhiza.lua) opens a Rex quick-launch layer, built on rexuikit's client, that lists every rhiza app; choosing one opens it in a modal.
