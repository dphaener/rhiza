## acceptance

The import topic states the rule; a testscript importing a fixture with one unbuilt task and one open question ends with one draft change set naming that Source and one open question, and accepts nothing.

## statement

The import procedure writes each unbuilt piece of planned work it finds as a draft intention change set with its intent and the Source it came from, and each open question it finds as a question node, and leaves accepting them to the owner.
