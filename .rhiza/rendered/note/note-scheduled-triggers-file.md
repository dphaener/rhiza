note · `01M6W5HWW57H2YBDNKXD94G199`

## statement

The intent says schedules live in a repo's rhiza.toml; decision scheduled-triggers-shape puts them in the committed .rhiza/dispatch.toml, because rhiza.toml is the root's machine-wide config shared by several projects. The leaves follow the decision. The intent's 'wrapping a command as an implicit one-step workflow' holds, on the main checkout with no change set.
