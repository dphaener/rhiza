# m24-service-or-tab

decision · `01M6FEKR2HP30S21ECT7JG0P1X`

## quote

The user can choose. Is this a server only installation, or do I want to just run the daemon in a tab on my mac (when Rex for Linux is available - the UI - we can expand to that as well). It needs to be flexible.

## statement

Each installation chooses how its daemon runs: a systemd service on a server, or a Rex tab on the Mac; starting and stopping the daemon works for both, leaving room for Rex's Linux UI later
