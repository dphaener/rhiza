# stalled-after-20-minutes

decision · `01M6A0MNY5QR1RSXNMW09VWDPZ`

## statement

A live run's session whose resolved hook status is working with a last report older than 20 minutes is stalled, except when paused for a usage limit; run status marks it stalled and the inbox lists it as a stalled item naming the session and its run; blocked and idle sessions are never stalled
