Going public exposes the whole git history and .rhiza/ log (Sources quote you, commits carry emails, session notes name machines). How do we prepare?

## statement

## wording

Audit, then you flip it: a change set audits history and .rhiza/ and fixes what it can going forward, reporting anything only a history rewrite would remove; the owner flips visibility by hand, no agent changes repo settings, picked by the owner
