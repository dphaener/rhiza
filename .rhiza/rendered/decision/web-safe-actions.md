# web-safe-actions

decision · `01M79NR6RCJKBRMGSRMA5A3G1A`

## question

Should the redesigned web UI stay read-only, or let you act on what needs you?

## statement

The web UI gains only safe actions (answer an inbox item, approve a sign-off, pause or resume) behind the web token; retry, abandon and merge stay with the CLI and the orchestrator.

## wording

A few safe actions (Recommended), picked by the owner
