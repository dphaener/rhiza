# m29-web-all-projects

decision · `01M6RN37HBF87AAE32A0XDWR37`

## question

What do the surfaces show once one daemon drives several projects?

## statement

The web UI has an all-projects home (each project's live runs, inbox count and health) and a merged inbox tagging each item with its project, and every existing page is scoped to one project through a switcher.

## wording

All-projects + per project. The assistant's option, picked by the owner.
