## quote_where

milestone-3 conversation, topic 5: the review workflow

## statement

The review workflow: a fresh session per check told only the change set ID; compliance, quality, hands-on QA with the built binary (fakes alone don't count), scope and model checks; a check fails only on a surviving blocker or major finding, with a critic that can't add findings; fixes routed per leaf, only failed checks re-run, at most 2 cycles, then a question or the arbiter; verdicts in the journal and the PR body; the owner signs off with rhiza run approve, skipped in autonomous mode.
