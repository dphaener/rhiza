# m24-only-agent-tabs

## quote

All these tabs that are open right now, whatever is watching the plan, that should also be swallowed up by the daemon. No need to see anything in a Rex tab that isn't doing agent work.

## statement

Run drivers move out of Rex into the daemon, so the only Rex tabs a run opens are its agent sessions
