# web-ui-design-basics

## quote

Motifs: fine glowing hyphae threads, small typed nodes (filled dot = intent, ring = capability, diamond = decision, square = constraint), always-dark terminals, pill buttons, 12–16px radii, thin 1px rules. No gradients, no emoji.

## statement

The design system starts from the owner's basics: dark-first 'bioluminescent soil', Petrona, Instrument Sans and JetBrains Mono, the soil and paper palettes with fungal gold, teal and rose accents, typed node glyphs, always-dark terminals, 12-16px radii, 1px rules, no gradients, no emoji.
