# m29-unready-listed

decision · `01M6RN37TYJ2EFRNWHT4PYK7JE`

## question

How does the root daemon treat a registered project that has no .rhiza/ yet (like Nebari before its import)?

## statement

A registered project with no .rhiza/ yet is listed as not initialised (in rhiza project ls, the web home and health) and the daemon starts no runs there until it has a model.

## wording

Listed, not built. The assistant's option, picked by the owner.
