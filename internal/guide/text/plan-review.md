# Plan review

A fresh review of a plan written into the model: a reviewer records findings, a critic
checks them, a reviser fixes the confirmed major ones. You are given a change set ID and one
role. This topic is an index; the guidance lives in three role topics. Load the one that is
yours, as a skill or with `rhiza guide <topic>`:

- Reviewer: `/rhiza-plan-reviewer` (`rhiza guide plan-reviewer`).
- Critic: `/rhiza-plan-critic` (`rhiza guide plan-critic`).
- Reviser: `/rhiza-plan-reviser` (`rhiza guide plan-reviser`).

Each role ends with `rhiza session done` as its own command, only once its recording command
has succeeded, as its topic says.
