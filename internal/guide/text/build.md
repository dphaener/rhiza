# Build

A build run takes a change set's leaves one at a time: a builder session, then a verifier
session. This topic is an index; the guidance lives in three role topics. Load the one
that is yours, as a skill or with `rhiza guide <topic>`:

- Builder: `/rhiza-builder` (`rhiza guide builder`). On a retry (`RHIZA_ATTEMPT` > 1) also
  `/rhiza-build-retry` (`rhiza guide build-retry`).
- Verifier: `/rhiza-verifier` (`rhiza guide verifier`).

Each role ends with `rhiza session done` as its own command, as its topic says.
